# 수량 분배 통합 (STEP1 월 계획 + STEP2 채널별 목표량)

설계·시뮬레이터: https://claude.ai/artifact/6w1DsAmLxKKPvDpryn5opX

## 배경

- STEP2가 처음 채워질 때만 STEP1 월 비중을 가져가고, 그 뒤로는 따로 움직여 월 분포가 어긋났다.
- 합계 기준이 세 개(총 발주량 · STEP1 합계 · STEP2 합계)라 MOQ 미달 배지·비례반영이 리오더 계획과 충돌했다.
- 대응SKU를 바꾸면 STEP2 수기 수정값이 안내 없이 덮어써졌다.

## 모델

| 값 | 정의 | 저장 |
|---|---|---|
| 채널×월 수량 | 유일한 원본 | `channelMonthQty` |
| 월 합계 | 채널 합계 + 마케팅 | 파생 |
| 월 비중(%) | 월 합계 ÷ 총 발주량. 리오더 계획이면 합 100% 초과 | `monthlySplit` (하위 호환용 파생 저장) |
| 채널 비중(%) | 채널 합계 ÷ 채널 전체 (마케팅 제외) | 파생 |
| 이번 발주량 | 총 발주량 입력값. 월 비중 기준선 | `totalOrderQty` |
| 시즌 판매 목표 | 월 합계의 합 (리오더 포함) | 파생 |

계산은 모두 `src/utils/qtyPlan.ts` 순수 함수. 검증: `npm run check:qty`.

## 조정 규칙

- **월 비중 수정 (STEP1)**: 그 달 월 합계 = 총 발주량 × 비중. 그 달 채널 구성비 유지. 확정 채널·마케팅 고정. 포커스 해제 시 반영.
- **채널 비중 수정 (STEP2)**: [채널 비중 수정] → 여러 채널 입력 → 저장. 월 합계 유지, 미수정 채널이 남은 비중을 현재 비율대로 배분. 반복 비례 조정(RAS)으로 각 채널의 월별 모양 최대한 유지.
- **칸 직접 수정**: 그 칸만 변경, 월 비중·채널 비중 재계산.
- **대응SKU 비중으로 다시 나누기**: 월 합계 유지, 확정 채널 제외. 대응SKU를 바꿔도 자동 실행 안 함(변경 안내만).
- **확정 채널**(플랫폼/브랜드/글로벌 확정): 모든 조정에서 제외. 전부 확정이면 비중 입력 잠금.
- **채널 끄기(재계산)**: 그 채널 수량을 같은 달 나머지 채널로 즉시 재배분(월 합계 유지). 켜기(재계산)는 다음 STEP2 진입 때 대응SKU 비중으로 다시 나눔.

## 발주량 커버 판정

`coverage()` — 누적 판매 목표가 발주량을 넘는 첫 달 표시.

| 판매 목표 vs 발주량 | 리오더 가능 (기본) | 시즌 한정 |
|---|---|---|
| 초과 | 리오더 시점·수량 | 품절 위험 |
| 같음 | 판매 목표 = 발주량 | 판매 목표 = 발주량 |
| 부족 | 잔여 재고 (다음 시즌 이월) | 과재고 위험 |

시즌 한정은 관리 탭 › 시즌 한정에서 지정 (`seasonOnly`). 주력 구분(시즈널/스테디/미해당)과 별개이고, 지정한 적 없으면 주력 시즈널만 시즌 한정으로 본다(`isSeasonOnly`).

## 함께 바뀐 것

- 비례반영·MOQ 미달 배지 제거. 시즌 한정만 [판매 목표를 발주량에 맞추기].
- '발주량 변경됨' 경고: 확정 시점 총 발주량(`finalOrderConfirmedOrderQty`) vs 현재 총 발주량.
- PM 확인 최종 발주량·발주서 기본값: STEP2 합계 → 총 발주량 × 옵션 비율.
- JSON 가져오기: 월 계획만 있고 채널×월이 비어 있으면 기본 채널 비중으로 채움.
